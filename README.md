# AI-Powered Automated Web Brochure Generator

An autonomous, two-stage LLM pipeline powered by the official Google GenAI SDK (`gemini-3.8-flash`) that scrapes, filters, and synthesizes raw corporate websites into executive Markdown brochures.

## Tech Stack
* Python 3.11+
* Google GenAI Native SDK (`google-genai`)
* BeautifulSoup4 & Requests
